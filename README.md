# Mission Radar Mondial

Dépôt public de transfert des rapports partageables de Mission Radar Mondial.

## Fichiers courants

- `latest_chatgpt.md` : rapport complet lisible
- `latest_chatgpt.json` : rapport structuré destiné aux traitements automatisés

## Archives

Les versions historiques sont conservées dans :

`archive/YYYY-MM-DD/`

## Sécurité

Ce dépôt ne doit contenir aucun mot de passe, token, credential, secret, donnée volée ou information confidentielle non destinée à la publication.

Les actions commerciales restent soumises à validation humaine L5.
